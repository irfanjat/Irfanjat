## 🚀 Featured Projects

### 🔷 End-to-End GitOps CI/CD Pipeline
`GitHub Actions` `ArgoCD` `Kubernetes` `Docker` `Helm`

Reduced deployment time by **80%** with zero-downtime releases using a dual-repository GitOps architecture. Implements CI with GitHub Actions (test, build, push, SHA-tag) and CD with ArgoCD for GitOps sync on Kubernetes with readiness probe validation and self-healing. Every deploy is an auditable Git commit with automatic rollback on failure.

[![Repository](https://img.shields.io/badge/View_Code-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/irfanjat/gitops-cicd-pipeline)

### 🔷 Production Multi-Tier AWS Infrastructure — Terraform IaC
`Terraform` `VPC` `EC2` `ALB` `Auto Scaling` `RDS` `S3` `DynamoDB`

Provisioned **24 production-grade AWS resources** with zero manual console interaction and full security compliance. Built 5 reusable Terraform modules (VPC, security groups, ALB, EC2, RDS) with S3 remote state, DynamoDB locking, AES-256 encryption, and least-privilege IAM policies. Repeatable infrastructure deployment across environments in minutes.

[![Repository](https://img.shields.io/badge/View_Code-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/irfanjat/terraform-aws-infra)

Unified 6-panel Grafana dashboard with live Loki log streams, CPU/memory metrics, and node-level health.
